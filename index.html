OPERATING NOTES

Independent reference. Clear boundaries.

This app is not Riot approved, Vanguard certified, or guaranteed safe for competitive use. A browser-only design does not establish policy approval. Use for pre-match study and custom-game practice; obtain Riot clarification before relying on it during competitive matches.

What runs on your machine

A single local HTML page with JavaScript. It filters manually selected reference material and saves your playbook in browser local storage. It does not read VALORANT processes, memory, files, network traffic, screenshots, or match state. It does not draw over the game, register global hotkeys, send inputs, or automate throws. The page permits images from two specific artwork/screenshot CDNs. Those servers receive ordinary image requests, including your IP address. No third-party scripts, embedded sites, video players, or analytics run inside the app. External source links open only when clicked.

Riot’s policy boundary

Riot lists in-game apps and overlays using real-time data to immediately change player behavior among unapproved use cases. This app supplies no live data or recommendations from a match. That architectural distinction is not an endorsement or a guarantee about any particular use.

Personal entries can contain your own setup steps and screenshots. “Personally tested” means only that you marked it tested; it is not independently verified.

Using the playbook

Select an agent, map, side and utility; search by location. Star entries for quick access. Add your own position, aim point, throw sequence, patch, and screenshot from a custom game. Focus mode enlarges a single entry. Shortcuts only work while this page has focus: / to search and Esc to close focus mode or a dialog.

Export regularly. Storage is tied to this browser and file location and can be cleared by browser settings. Import merges validated records, preserving existing entries with matching IDs. Your screenshots and GIFs are stored locally and included in exports. Large GIFs can fill browser storage; export regularly. Built-in gallery images load from their publisher and are not included in backups. No cloud sync or analytics.
